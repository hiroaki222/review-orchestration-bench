# review-orchestration-bench

**English** | [日本語](./README.ja.md)

A cost-vs-performance benchmark for AI code review orchestration configurations (single, parallel-aspect, adversarial, multi-run aggregation).

## Key Findings (SIG-AGI 33rd, 2026-08)

- **12 models × 4 configurations × 30 items = 1440 combos** measured (total API spend: $79.79).
- **GPT-5 mini + Multi-run** is best: $F_2 = 0.826$ (95% bootstrap CI $[0.746, 0.903]$), $0.0206/item.
- **Multi-run** achieves the highest per-configuration average $F_2 = 0.602$ and wins in 8 of 12 models.
- **9 of 12 models** fall off the cost-$F_2$ Pareto front; cheap models with Multi-run outperform premium single-shot selection.
- Beyond **$0.05/item**, quadrupling the budget yields no further improvement in achievable maximum $F_2$.

![Cost-vs-F2 Pareto](docs/img/pareto_full.png)

## Benchmark

- **30 items**: synthetic PRs generated by inverting bug-fix commits from 4 repositories, providing a reviewer-target diff and the ground-truth fix location.
- **Repositories**: fastapi (Python / web framework), valibot (TypeScript / schema validation), chi (Go / HTTP router), pgrust (Rust / DB engine).
- **Leakage control**: pgrust's history is post-2026-06, after the knowledge cutoff of the models under study.
- **Bug categories**: logic, type-safety, error-handling, concurrency, security, and others (8 categories).

## Orchestration configurations

| Configuration | Calls | Description |
|---|---|---|
| **Single** | 1 | Single reviewer covers all aspects. |
| **Parallel** | 4 | Four aspects (correctness, concurrency, api-misuse, security) run independently; findings are unioned. |
| **Adversarial** | $1+2k$ | Initial reviewer call plus two refutation prompts per finding $k$; a finding is kept if at least half of the refutations support it. |
| **Multi-run** | 5 | Same prompt run five times; a finding is kept if voted by at least two of five runs. |

## Models (12 across 3 vendors)

- **Anthropic**: Haiku 4.5, Sonnet 5, Opus 5, Fable 5
- **OpenAI**: GPT-5 mini, GPT-5, GPT-5.6 luna, GPT-5.6 terra, o3
- **Google**: Gemini 3.5 flash-lite, 3.6 flash, 3.1 pro-preview

## Reproducing

```bash
# Install dependencies
uv sync

# Environment (set in .env)
# ANTHROPIC_API_KEY, OPENAI_API_KEY, GOOGLE_API_KEY, PAPER_EMAIL

# Run experiment (models and configs are comma-separated)
uv run scripts/run_experiment.py \
  --run-name my-run \
  --models claude-haiku-4-5,gpt-5-mini \
  --configs single,parallel,adversarial,multi

# Analyze and generate paper tables/plots
uv run scripts/analyze.py --run my-run --save --paper-dir docs/paper/sigagi/
uv run scripts/plot_pareto.py --run my-run --out docs/paper/sigagi/fig/pareto.pdf
uv run scripts/plot_budget.py --run my-run --out docs/paper/sigagi/fig/budget.pdf

# Build the paper
./docs/paper/sigagi/build.sh
```
