# review-orchestration-bench

同一予算下で, AI コードレビューのオーケストレーション構成 (単一 / 観点別並列 / 敵対的批評 / multi-run 集約) の欠陥検出性能とコスト効率を比較するベンチマーク研究.

A benchmark for comparing AI code review orchestration configurations (single, parallel-aspect, adversarial, multi-run aggregation) under matched cost budgets, measuring defect detection performance and cost efficiency.
